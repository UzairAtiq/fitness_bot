# `.env.example` Documentation

### 1. Purpose
Provides a safe template defining all required and optional environment variable keys needed to run the backend service.

### 2. What It Does
- Template definitions: Documents keys for `QDRANT_URL`, `collection_name`, `QDRANT_API_KEY`, `GROQ_API_KEY`, and `SHARED_ACCESS_KEY`.

### 3. Depends on / Used by
- **Depends on**: External service accounts (Groq Cloud, Qdrant Cloud).
- **Used by**: Developers setting up a local `.env` copy via `cp backend/.env.example backend/.env`.

### 4. How to Modify
1. If a new API credential or config flag is introduced in `app/config.py`, add its key name and a placeholder value to `backend/.env.example`.
2. Do not include real secrets or actual API keys in this example template.

### 5. What to Add Here / What NOT to Add Here
- **Add here**: Placeholder variable names and comments explaining key formats.
- **Do NOT add here**: Production API keys, private passwords, or active secrets.
